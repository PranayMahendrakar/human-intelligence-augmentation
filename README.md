# 🧠 Human Intelligence Augmentation Framework

**Author: Pranay M.**

Integrated system that enhances human cognitive abilities across multiple dimensions simultaneously.

## 🌟 Features

| Module | Description |
|--------|-------------|
| **Memory Enhancer** | Enhance memory and recall |
| **Reasoning Amplifier** | Amplify logical reasoning |
| **Creativity Catalyst** | Catalyze creative thinking |
| **Focus Optimizer** | Optimize attention and focus |
| **Learning Accelerator** | Accelerate learning processes |
| **Decision Enhancer** | Enhance decision-making |
| **Problem Solver** | Augment problem-solving |
| **Knowledge Synthesizer** | Synthesize complex knowledge |
| **Metacognition Coach** | Develop metacognitive skills |
| **Cognitive Dashboard** | View cognitive enhancement metrics |

## 🚀 Quick Start

```bash
ollama pull llama3.2 && ollama serve
pip install -r requirements.txt
python main.py
```
